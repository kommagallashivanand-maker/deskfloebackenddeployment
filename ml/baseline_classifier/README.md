# DeskFlow - Baseline Ticket Category Classifier

DeskFlow Baseline Classifier is a production-ready, deterministic Python module for classifying customer support tickets into 10 categories using TF-IDF feature extraction and Logistic Regression.

## Project Overview

This baseline classifier predicts ticket categories using both the `title` and `body` fields generated by the dataset generator. It provides a reproducible benchmark model (`baseline_v1`) to evaluate future iterations (e.g. embeddings, transformer models, model registry).

### Key Features
- **Deterministic & Reproducible**: Built with fixed random seeds (`random_state=42`) and stratified train/test splits.
- **Combined Text Processing**: Concatenates ticket titles and bodies inside a scikit-learn `Pipeline` via `FunctionTransformer`.
- **Modular & Encapsulated**: Preprocessing, vectorization, and classification steps are serialized into a single joblib pipeline object.
- **Detailed Evaluation & Diagnostics**: Generates classification reports, confusion matrix CSVs, JSON metrics, and markdown training summaries.

## How to Run

### 1. Training the Model

To train the baseline model and save artifacts to `models/` and `reports/`:

```bash
python train.py
```

Or from the root workspace directory:

```bash
python ml/baseline_classifier/train.py
```

#### Training Sequence
1. Loads dataset from `ml/dataset_generator/datasets/tickets_v1.csv`.
2. Validates schema (`ticket_id`, `title`, `body`, `category`) and filters empty records.
3. Performs a stratified 80/20 train/test split (`random_state=42`).
4. Fits the `Pipeline([text_combiner, TF-IDF, LogisticRegression])`.
5. Evaluates model metrics and exports reports to `reports/`.
6. Serializes model to `models/baseline_v1.pkl` and metadata to `models/baseline_v1_metadata.json`.

### 2. Making Predictions

#### CLI Usage
Run predictions from the command line:

```bash
python predict.py --title "Unable to reset password" --body "Password reset link expires immediately after clicking."
```

Output:
```text
Prediction: Account Access
Confidence: 39%
```

#### Python API Integration
Import `predict` function into other Python services:

```python
from ml.baseline_classifier.predict import predict

result = predict(
    title="Having trouble billing credit card",
    body="The payment gateway returns credit card validation error code 43022."
)
print(result)
# Output: {'category': 'Billing', 'confidence': 0.60}
```
